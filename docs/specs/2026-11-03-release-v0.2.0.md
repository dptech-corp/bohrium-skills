# Bohrium Skills 0.2.0 release

## Goal

Publish the current CLI-backed Skills and Gemini extension through the existing GitHub Release and npm workflow, with migration information for users of 0.1.1.

## Current evidence

- GitHub Release and npm latest are both 0.1.1 at `b600fee892a3d49e4673622ab83a1e4eb3403a8e`; main `c58e5d275e087070454122f8a5f8ba237dfed21a` has passed CI and includes the Gemini manifest and regular Skill directories.
- The previous published Skill set shipped Python API scripts. The current 17 workflows use `bohr`; those scripts and example payloads have been removed.
- The release workflow builds six platform binaries, creates a GitHub Release, and publishes npm on tag pushes. The npm postinstall selects the binary for the exact package version.

## Requirements and decisions

- Use version 0.2.0 for the npm package, generic plugin and Gemini extension; keep the source CLI guide lock unchanged.
- Describe the CLI migration, removed scripts, required `bohr` installation and authentication, and supported installation paths in release-facing material.
- Use the existing release workflow, preserving earlier tags, packages and existing user files. No local npm publish or rewrite of older releases.
- Add the `gemini-cli-extension` repository topic after verifying the new default install; report gallery indexing separately.

## Acceptance criteria

- Package version, plugin version, Gemini manifest version and tag are 0.2.0; `v0.2.0` and npm 0.2.0 are unoccupied before publishing.
- Release CI succeeds, six binaries and checksums appear on the new release, and npm 0.2.0 points to the release commit.
- A fresh Gemini default install discovers all 18 Skills and complete reference trees; a fresh npm install and version check exercise the released artifacts in an isolated development-host directory. Report network or authentication blockers without substituting a mock.
- Users can find a clear description of breaking migration relative to v0.1.1 and the CLI prerequisite.

## Scope and dependencies

The existing GitHub and npm publishing permissions, Actions, registry and Gemini gallery are external dependencies. Actual scientific business calls, Google gallery indexing and npm distribution are separate observations; no production business data is modified.
