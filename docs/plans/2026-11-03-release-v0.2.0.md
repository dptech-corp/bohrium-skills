# Bohrium Skills 0.2.0 Release Plan

**Goal:** Publish the existing CLI-backed Skills and Gemini extension as 0.2.0.

**Architecture:** Align version metadata and migration documentation on a release branch; use existing GitHub Actions to produce the Release and npm package. Verify installed artifacts from clean development-host directories.

**Tech Stack:** GitHub Actions, npm, Go, Gemini CLI.

**Spec:** `docs/specs/2026-11-03-release-v0.2.0.md`

## Global Constraints

- Previous published baseline is `v0.1.1` / npm `0.1.1` at `b600fee892a3d49e4673622ab83a1e4eb3403a8e`.
- Version must be `0.2.0`; use the existing release workflow and never publish npm locally.
- Validate on the development host or matching CI; do not modify older releases or business data.

### Task 1: Prepare and validate release inputs

**Files:** `package.json`, `plugin.json`, `gemini-extension.json`, `docs/cli.md`, `CHANGELOG.md`.

- [ ] Change the three package and extension versions to `0.2.0` and describe 0.1.1-to-0.2.0 migration in the changelog.
- [ ] Update installer documentation so 0.1.1 is clearly historical and 0.2.0 documents current target directories and assets.
- [ ] On the development host confirm the version guard accepts 0.2.0 and rejects mismatches, and that the npm package contains only its declared runtime files. Reuse the green main CI for unchanged code.
- [ ] Review the complete diff and release notes relative to v0.1.1. Commit and publish only with the authorization required by the active Git instructions.

### Task 2: Release and verify

- [ ] Merge the version change through the repository's PR flow after CI, verify the exact main commit and unused version, then push `v0.2.0` for the existing Actions workflow.
- [ ] Verify the workflow, tag, six release binaries, checksum file, release notes, npm metadata and `gitHead`.
- [ ] In task-owned isolated directories install the public npm package and default Gemini extension; validate version, all 18 Skills, and complete references. Report real network failures or unavailable model access.
- [ ] Add `gemini-cli-extension` to the repository topics and read it back after install verification; separately report whether Google has indexed the extension.
