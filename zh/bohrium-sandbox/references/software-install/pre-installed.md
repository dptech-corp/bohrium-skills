# Pre-installed software on the Bohrium image

Source: <https://docs.bohrium.com/docs/userguide/image>

Before installing, run `which <cmd>` or `pip show <pkg>` to check whether it is
already present — most common scientific tooling ships with the image.

## Inventory

- **Python stack** — Python 3.10, `pip`, Anaconda, Jupyter Lab.
- **File tools** — `wget`, `curl`, `unzip`, `emacs`, `vim`, `rsync`, `tree`, `git`.
- **Build toolchain** — `cmake`, `build-essential`.
- **System utilities** — `htop`, `ncdu`, `net-tools`.
- **DP ecosystem** — Lebesgue Utility, DP-Dispatcher, Dpdata.
